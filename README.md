# Usuarios

## Descrição

-  A diferencia entre um funcionario e um Usuario é que o funcionario é com certeza um caminhoneiro que tem a responsabilidade sobre um caminhão, enquanto um Usuario é alguem que ira acessar o aplicativo de alguma forma

Ex: Um admin (Usuario) registra um Funcionario
Um Usuario olha seu registro como Funcionario

## Atributos

- Senha
- Nome
- Id (Primario)
- Nivel de Permissão
